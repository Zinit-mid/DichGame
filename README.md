# Dịch Game (Anh → Việt)

App Windows đọc chữ tiếng Anh trên màn hình game (phụ đề, nhiệm vụ, menu) và hiện bản dịch tiếng Việt đè lên game.

- Đọc chữ: Windows OCR
- Dịch: Claude AI (dự phòng Google Dịch miễn phí)
- Chụp màn hình: Windows Graphics Capture / DXGI

Tải bản mới nhất ở mục **Releases** (file `DichGame.exe`). Hướng dẫn: xem `HUONG_DAN.txt`.
